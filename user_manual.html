    ⚡ Overview

    EUROTRACKER is a 6‑track CV/Gate hardware sequencer for modular synthesizers. It combines a tracker‑style song grid with per‑step probability, ratchet, microtiming, swing, and full envelope control. Tracks 1–4 drive CV outputs through a real‑time quantizer with 18 selectable scales. All parameters are saved automatically to internal flash.

    🎼 Song Screen (main view)

    6 tracks × up to 64 song steps. Each step holds a 32‑step pattern (length 1‑32).

    • Joystick – move cursor (track / step).
    • ENC A rotate – rotate current pattern (shift all steps).
    • ENC B rotate – change step divider (x4 … /4).
    • ENC A click – copy pattern to buffer.
    • ENC B click – paste pattern (if buffer exists).
    • Joystick click – enter pattern edit screen.
    • Hold ENC A (500ms) – open Track Settings (works during playback).
    • Hold joystick (500ms, stopped) – open Global Settings.
    • SAVE short press – start/stop playback / loop step mode.
    • SAVE long press – stop playback and mark project dirty.

    📀 Pattern Edit Screen

    32‑step grid (4 rows × 8 columns). Edit per‑step parameters. A preview overlay appears when a parameter is changed, showing the current value, the physical unit (volts or milliseconds), and the DAC value for CV.

    • Joystick – move cursor.
    • Joystick click – toggle step on/off.
    • ENC A click – cycle edit mode: CV → Decay → Attack.
    • ENC B click – cycle edit mode: Probability → Gate Length → Ratchet → Microtiming.
    • ENC rotate – adjust current parameter.
    • Hold joystick (500ms) – open Pattern Settings (divider, length, transpose). Works during playback, but Length is disabled while playing.
    • SAVE short press – exit to song screen (marks project dirty).

    🎛️ Track Settings (per track)

    Hold ENC A 500ms in song screen. Accessible during playback for non‑structural edits.

    • Quantizer – shows ON/OFF and opens the Quantizer sub‑menu.
    • CV Low / High – voltage range (0–4095 → 0–5V). Shown as Lowest Note / Highest Note when the quantizer is active; the value is stepped by note index.
    • Swing – 0–100% shuffle (applied to odd steps, overridden by microtiming).
    • Reset Step – RESET = AR envelope restarts from zero; KEEP = glide/portamento from previous CV.

    🎯 Quantizer Sub‑menu

    Opens from Track Settings → Quantizer. Only available on tracks 1–4.

    • Enable – ON/OFF. When ON, the CV output snaps to the nearest active note in the current scale.
    • Generate – opens a sub‑menu to build the chromatic grid:
      • Min CV – lowest DAC value
      • Max CV – highest DAC value
      • Num Notes – 2 to 128
      The resulting note list is evenly spaced across the range and named from C4 upward. Editing Min CV or Max CV previews the value on the track's CV output. Generate is disabled during playback.
    • Scale – opens the scale sub‑menu:
      • Scale – select one of 18 built‑in scales
      • Root – select the root note (c, C, d, D, e, f, F, g, G, a, A, b)
      • Apply – apply the scale to the note grid
      The quantizer menu shows the currently applied scale as Scale: <root> <name>, or Custom if the note grid was hand‑edited after the last Apply.
    • Notes – opens the note editor. Each note is listed with its name and DAC value. Scroll with the joystick, toggle in‑scale status with the joystick click, edit DAC with the encoders, and preview each note on the track's CV output as you navigate.

    Built‑in Scales

    Chromatic, Major, Natural Minor, Pentatonic Major, Blues, Harmonic Minor, Melodic Minor, Dorian, Phrygian, Lydian, Mixolydian, Locrian, Whole Tone, Diminished, Augmented, Hungarian Minor, Lydian Dominant, Super Locrian.

    📋 Pattern Settings

    Hold joystick inside pattern edit.

    • Divider – clock division for the step (x4 … /4).
    • Length – pattern length 1‑32. Disabled during playback.
    • Transpose – shift all CV values in pattern (±12 semitones).
    • Save & Exit / Exit w/o Save – exit options.

    🌍 Global Settings

    Hold joystick in song screen (stopped).

    • Clock Source – Internal BPM / External PPQN. Selecting external also reconfigures the clock pin as an input. Selecting internal reconfigures it as an output.
    • Internal BPM – 30–300, editable to 0.1 BPM accuracy.
    • External PPQN – 1, 2, 4, 24, 48. Also used as the clock output rate when internal source is selected.
    • Autoplay – start playback on power‑up.
    • Sync Start – wait for the next clock tick before starting.
    • Joystick Speed – cursor sensitivity.
    • Brightness – display contrast.
    • Song Length – number of song steps (1‑64).
    • New Song – clear current project (warning dialog).
    • Save / Load Song – store to/from 8 internal slots.
    • Save and Exit / Exit w/o Saving.

    📈 Gate & CV Envelopes – Duration Mapping

    Gate Length, Attack, Decay are stored as 0‑99 and scaled relative to the current 1/16th note duration. The mapping (from calculateDurationUs()):

    • 0 → minimum gate ~120 µs (short click).
    • 1‑32 → linear from very short up to half of a 1/16th note.
    • 33‑96 → from half a 1/16th note up to 32 sixteenth notes (one full pattern of 32 steps).
    • 97 → 128 × halfStep → 64 sixteenth notes (2 patterns).
    • 98 → 256 × halfStep → 128 sixteenth notes (4 patterns).
    • 99 → 512 × halfStep → 256 sixteenth notes (8 patterns).

    Example: At 120 BPM, a 1/16th note = 125 ms. Value 50 gives roughly half of that (62.5 ms). Value 96 gives exactly 32 sixteenth notes (4 seconds).

    Attack/Decay use the same mapping when Reset Step = RESET (AR envelope). When Reset Step = KEEP, Attack/Decay act as portamento time (rise/fall) relative to the same scale.

    🎚️ Clock & Synchronization

    Internal BPM (30–300) or external clock (1–48 PPQN). The sequencer automatically switches between modes. External sync uses a soft phase‑locked loop to track the incoming clock and keep step boundaries aligned with the external pulse.

    When the internal clock is selected, the CLOCK pin becomes an output and toggles at the configured PPQN rate — useful for driving other modules from EUROTRACKER as the master clock.

    Sync Start ensures playback begins on the next quarter‑note boundary for tight sync with other devices.

    💾 Project Management

    Auto‑save every 15 seconds while stopped, if changes have been made. Manual save with long press of SAVE button (marks project dirty). Use Save Song / Load Song in global settings to store/recall projects to/from 8 internal slots (/song1.song … /song8.song). New Song clears all data after confirmation.

    ▶️ Editing During Playback

    Track Settings and Pattern Settings can be opened while the sequencer is running. Parameters that only modify existing data (swing, CV range, scale, notes, divider, transpose) apply immediately. Two parameters are disabled during playback because they reallocate memory that the playback engine is reading:

    • Generate (in the Quantizer sub‑menu)
    • Length (in Pattern Settings)

    Both become available again when playback is stopped.

    ⚡ 概述

    EUROTRACKER 是一款适用于模块合成器的 6 轨 CV/Gate 音序器。它结合了 tracker 风格的乐曲网格，支持每步概率、连击、微移、摇摆以及完整的包络控制。轨道 1–4 通过带 18 种音阶的实时量化器驱动 CV 输出。所有参数会自动保存到内部闪存。

    🔌 接口定义

    端口功能规格
    ⚡ CLOCK外部时钟输入 / 主时钟输出1–48 PPQN, 5V。自动切换：选择外部时钟时作为输入，选择内部时钟时作为输出。
    🎛️ CV A … D控制电压输出0–5V, 12‑位 (0–4095)
    🔘 GATE 1 … 6门限输出0–5V, 可编程长度
    🕹️ 摇杆 + 按下导航与确认4 方向 + 中心点击
    🔘 编码器 A / B + 按下数值编辑 / 复制粘贴旋转编码器带按键
    💾 SAVE 键播放控制 / 保存短按：开始/停止/循环步；长按：停止并标记保存

    🎼 乐曲界面（主视图）

    6 轨 × 最多 64 个乐曲步。每个步包含一个 32 步的音序样式（长度 1‑32）。

    • 摇杆 – 移动光标（轨道 / 步）。
    • 编码器 A 旋转 – 旋转当前样式（整体移位）。
    • 编码器 B 旋转 – 更改步除法器（x4 … /4）。
    • 单击编码器 A – 复制样式到剪贴板。
    • 单击编码器 B – 粘贴样式（若剪贴板有数据）。
    • 单击摇杆 – 进入样式编辑界面。
    • 长按编码器 A (500ms) – 打开轨道设置菜单（播放中可用）。
    • 长按摇杆 (500ms, 停止时) – 打开全局设置。
    • 短按 SAVE – 开始/停止播放 / 循环步模式。
    • 长按 SAVE – 停止播放并标记为待保存。

    📀 样式编辑界面

    32 步网格 (4 行 × 8 列)。编辑每步的参数。编辑参数时会弹出预览窗，显示当前数值、物理单位（伏特或毫秒）以及 CV 的 DAC 数值。

    • 摇杆 – 移动光标。
    • 单击摇杆 – 切换步的启用/禁用。
    • 单击编码器 A – 循环编辑模式：CV → 衰减 → 起音。
    • 单击编码器 B – 循环编辑模式：概率 → 门限长度 → 连击 → 微移。
    • 旋转编码器 – 调整当前参数数值。
    • 长按摇杆 (500ms) – 打开样式设置（除法器、长度、移调）。播放中可打开，但长度在播放时禁用。
    • 短按 SAVE – 退出返回乐曲界面（标记为待保存）。

    🎛️ 轨道设置（每条轨道独立）

    在乐曲界面长按 编码器 A 500ms。播放中可以打开进行非结构性编辑。

    • 量化器 – 显示开/关并打开量化器子菜单。
    • CV 低 / 高 – 电压范围（0–4095 → 0–5V）。量化器开启时显示为最低音 / 最高音，并按音名索引步进。
    • 摇摆 – 0‑100% shuffle（作用于奇数步，被微移覆盖）。
    • 步复位 – RESET = AR 包络从零开始；KEEP = 从前一 CV 滑音/连奏。

    🎯 量化器子菜单

    从 轨道设置 → 量化器 打开。仅轨道 1–4 可用。

    • 启用 – 开/关。开启时 CV 输出会吸附到当前音阶中最近的可用音符。
    • 生成 – 打开子菜单以构建半音网格：
      • Min CV – 最低 DAC 值
      • Max CV – 最高 DAC 值
      • Num Notes – 2 至 128
      生成的音名列表在整个范围内均匀分布，从 C4 开始命名。编辑 Min CV 或 Max CV 时会在该轨道的 CV 输出上预览数值。播放时生成功能禁用。
    • 音阶 – 打开音阶子菜单：
      • Scale – 从 18 个内置音阶中选择
      • Root – 选择根音（c, C, d, D, e, f, F, g, G, a, A, b）
      • Apply – 将音阶应用到音符网格
      量化器菜单显示当前应用的音阶为 Scale: <root> <name>，若在上次应用后手动编辑了音符网格则显示 Custom。
    • 音符 – 打开音符编辑器。每个音符列出其名称与 DAC 值。使用摇杆滚动，单击摇杆切换 in‑scale 状态，使用编码器编辑 DAC 值，导航时会在该轨道的 CV 输出上预览当前音符。

    内置音阶

    半音阶、大调、自然小调、大调五声、布鲁斯、和声小调、旋律小调、多利亚、弗里吉亚、利底亚、混合利底亚、洛克里亚、全音阶、减音阶、增音阶、匈牙利小调、利底亚属、超洛克里亚。

    📋 样式设置

    在样式编辑界面长按摇杆。

    • 除法器 – 该步的时钟分频 (x4 … /4)。
    • 长度 – 样式步数 1‑32。播放时禁用。
    • 移调 – 整体移调样式内所有 CV 值（±12 半音）。
    • 保存并退出 / 不保存退出 – 退出选项。

    🌍 全局设置

    在乐曲界面长按摇杆（停止时）。

    • 时钟源 – 内部 BPM / 外部 PPQN。选择外部时会将时钟引脚重新配置为输入；选择内部时重新配置为输出。
    • 内部 BPM – 30–300，精度 0.1 BPM。
    • 外部 PPQN – 1, 2, 4, 24, 48。内部时钟源时同样用作时钟输出速率。
    • 自动播放 – 开机自动开始播放。
    • 同步启动 – 等待下一个时钟脉冲再开始。
    • 摇杆速度 – 光标移动灵敏度。
    • 亮度 – 屏幕对比度。
    • 乐曲长度 – 乐曲步数 (1‑64)。
    • 新建工程 – 清空当前工程（确认对话框）。
    • 保存/读取工程 – 存储到 8 个内部插槽。
    • 保存并退出 / 不保存退出。

    📈 门限与 CV 包络 – 时长映射表

    门限长度、起音、衰减 参数范围 0‑99，它们映射的实际时长基于当前的 1/16 音符时长。映射规则（来自 calculateDurationUs()）：

    • 0 → 最小门限约 120 µs（短促触发）。
    • 1‑32 → 线性从极短到 半个 1/16 音符。
    • 33‑96 → 从半个 1/16 音符到 32 个十六分音符（一个完整的 32 步样式）。
    • 97 → 128 × 半步长 → 64 个十六分音符（两个样式）。
    • 98 → 256 × 半步长 → 128 个十六分音符（四个样式）。
    • 99 → 512 × 半步长 → 256 个十六分音符（八个样式）。

    示例：120 BPM 时，1/16 音符 = 125 ms。数值 50 对应约一半长度（62.5 ms）。数值 96 对应整整 32 个十六分音符（4 秒）。

    起音/衰减 在 步复位 = RESET 时使用相同的映射（AR 包络）。当 步复位 = KEEP，起音/衰减作为滑音时间（上升/下降），同样使用该比例。

    🎚️ 时钟与同步

    支持内部 BPM（30–300）或外部时钟（1–48 PPQN）。音序器自动切换模式。外部同步使用软锁相环跟踪输入时钟，使步进边界与外部脉冲对齐。

    选择内部时钟时，CLOCK 引脚变为输出，按配置的 PPQN 速率翻转 —— 可将 EUROTRACKER 用作主时钟驱动其它模块。

    同步启动 确保播放从下一个四分音符边界开始，实现与其它设备的紧密同步。

    💾 工程管理

    停止状态下，若有改动，每隔 15 秒自动保存。长按 SAVE 键手动保存（标记为待保存）。在全局设置中使用 保存工程 / 读取工程 可将工程存储到 8 个内部插槽（/song1.song … /song8.song）。新建工程 会清空所有数据（需确认）。

    ▶️ 播放中编辑

    播放中可打开轨道设置与样式设置。仅修改现有数据的参数（摇摆、CV 范围、音阶、音符、除法器、移调）会立即生效。两个参数在播放中被禁用，因为它们会重新分配播放引擎正在读取的内存：

    • 生成（量化器子菜单中）
    • 长度（样式设置中）

    停止播放后二者恢复可用。
